# ReadySuite 官网

[English](README.md)

ReadySuite 产品的中英文官方网站：

- ReadyType 1.5.0：中文优先的 macOS 语音输入应用。
- ReadyCheck 0.1.75：适用于 macOS 与 Windows 的 Codex 用量查看工具。
- CrossFit WHOOP Video 1.0.11：竖屏 4K 运动视频制作工作流。

## 本地预览

```bash
npm install
npm run dev
```

打开 http://localhost:3000

## 生产构建

```bash
npm run build
```

## 部署

在当前目录执行：

```bash
vercel --prod
```

产品下载链接指向各项目最新的 GitHub Release 或仓库。

生产环境地址：[readysuite.vercel.app](https://readysuite.vercel.app/)

## 推广执行

[推广执行包](docs/launch/README.md)包含渠道跟踪链接、可直接发布的文案、隐私检查和
每周指标模板。Vercel Analytics 仅记录产品入口、下载、发布、支持、文档和语言切换
事件，不采集表单内容或账号数据。
